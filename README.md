# misc-projects
Miscellaneous Projects that I've worked on over the years assigned from the Front End Development course on https://www.scrimba.com.

## Browse the archive

Run `npm install` once, then `npm start` from this folder and open
[the local project gallery](http://127.0.0.1:4173).

The gallery includes all nine projects, with previews, search, and a project viewer.
Original project files are preserved. See [gallery/README.md](gallery/README.md)
for details and troubleshooting.
